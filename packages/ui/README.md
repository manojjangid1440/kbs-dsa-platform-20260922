# Shared web UI

Manually installed shadcn/ui source primitives (Button, Card, Badge, Input and Dialog), using React, Radix Slot, class-variance-authority and Tailwind. Component API follows shadcn/ui's editable-source pattern. Registry configuration is included; web-only. Native imports shared tokens instead.

Reference: https://ui.shadcn.com/docs/installation/manual and https://ui.shadcn.com/docs/monorepo. Extend with official registry components as feature screens land. No unrelated UI framework is introduced.
